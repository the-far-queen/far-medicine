## CAUTION — CC BY-NC-SA (share-alike and non-commercial bind)

### OpenStax
License: **Creative Commons Attribution-NonCommercial-ShareAlike 4.0
International.** Verified on openstax.org 2026-10-06 — the site footer
states: "Except where otherwise noted, textbooks on this site are
licensed under a Creative Commons Attribution-NonCommerical-ShareAlike
4.0 International License."

**OpenStax is frequently misdescribed as CC-BY. It is not.** NC and SA
both bind. A derivative cannot be relicensed MIT, and it cannot be used
in a commercial product. Our repos are non-commercial today, so use is
currently permitted — as a standing constraint, not a permanent right.

### A note on trusting URLs from memory

Two of the three source records written from memory in this session were
wrong: a Gutenberg ebook ID that belonged to a French magazine, and an
OpenStax book slug that does not exist. Both looked entirely plausible.
The only reliable procedure is to fetch and read the page before
recording it.
